do you want to change the hit position?

well, first you must open the "script-key" file in which you want to make the modification:

"script-key-4K.mui" (for 4k)
"script-key-5K.mui" (for 5k)
"script-key-6K.mui" (for 6k)
"script-key-7K.mui" (for 7k)

then at the beginning of the script-key you must edit the value in "@define HITPOSITION" using numbers from 0 to 200 (I do not recommend exceeding 150).
